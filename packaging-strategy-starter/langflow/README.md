# Langflow

Put the exported flow from Workshop 4 here (the research pipeline: Planner, Summarizer, Reviewer, Writer).

## Before you upload

Open the exported `.json` file in a text editor and search for `key`, `token`, `secret`, and `password`. If an API key appears, remove it or do not upload the file.

## Why it belongs in a repository

A flow is just a text file. Once it is here, every change can be reviewed and an earlier version can be restored.
