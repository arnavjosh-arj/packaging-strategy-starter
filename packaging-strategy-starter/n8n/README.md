# n8n

Put the downloaded workflow from Workshop 5 here: **Supplier Quote Automation** (form trigger, calculation, AI briefing, 15% decision, human approval, log to a sheet).

## To use it

In your own n8n, import the `.json` file. You will need to connect your own credentials for the Google Gemini model and for Google Sheets.

## Before you upload

Open the file in a text editor and search for `key`, `token`, `secret`, and `password`. Never upload secrets.
