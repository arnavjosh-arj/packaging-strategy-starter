# Packaging Strategy Starter

A teaching repository for the AI for Business workshop series (Fordham University). It keeps the work from Workshops 1-5 in one place, so a team can review changes, track tasks, and recover earlier versions.

**Scenario:** a strategy team is deciding whether to switch to eco-friendly, compostable packaging, and then handling supplier price quotes. All numbers come from four teaching documents and are not real company data.

## What is in here

| Folder | What it holds | Workshop |
|---|---|---|
| `docs/` | The decision memo (draft) and the supplier quote policy | 1, 2, 5 |
| `langflow/` | The agent flow built in Langflow | 4 |
| `n8n/` | The supplier quote automation built in n8n | 5 |
| `notebooklm/` | The source list and notes from NotebookLM | 2 |

## How to use it

1. Click **Fork** (top right) to make your own copy.
2. Open the **Issues** tab to see the team's task list.
3. Try the pull request flow: create a branch, edit a file, commit, and open a pull request in your own copy.

## Before you upload anything new

Never upload API keys, tokens, or passwords. Exported flows and workflows should be opened in a text editor and searched for `key`, `token`, `secret`, and `password` first.
